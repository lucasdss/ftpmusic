# Archived collection cover packs

These style packs were generated with ChatGPT via Motile LiteLLM but are **not
shipped in the APK**. Restore later by:

1. Move `scripts/collection_defaults/archived_packs/{packId}` →
   `compose/app/src/main/assets/collection_defaults/{packId}`
2. Add the pack entry to `assets/collection_defaults/packs.json`
3. Add the label row in Appearance settings (or load packs from catalog)

Shipped packs: `anime`, `futuristic`, `vintage`, `watercolor`, `noir`.

Archived here: `pixel48`, `bauhaus`, `clay`, `risograph`.

Prompts remain in `../prompts.json` for regeneration with
`scripts/generate-collection-default-covers.py --pack <id>`.
